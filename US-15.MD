
## US-15 — Registrar serie

El formulario está en `src/components/entrenar/FormularioSerie.jsx`. Recibe sus
datos por props y usa `useFormularioSerie` para la edición y los mensajes.
`useRegistrarSerie` valida el formato y coordina los services. La traducción
entre camelCase y snake_case queda en los services, incluido el plan vigente.

Se precargan peso, repeticiones y RIR de la última serie de hoy, o de la última
sesión si todavía no hay series hoy. Los datos que llegan tarde no sobrescriben
campos editados. El peso admite coma decimal y hasta dos decimales; 0 representa
peso corporal. No hay selector de fecha ni se envían fecha, número de serie o
identidad del deportista.

El registro se confirma con un toque. Se bloquea el doble envío y se muestran
los motivos del backend textualmente. La numeración, el cumplimiento y los
récords se toman del servidor. Si el POST se confirma pero falla la consulta
posterior, «Actualizar sesión» reintenta solo la consulta, sin repetir el POST.

Para probar este flujo mientras faltan las piezas del backend, usar en `.env`:

```dotenv
VITE_API_URL=http://localhost:3000/api
VITE_USE_MOCKS=true
```

Ingresar como Juan y abrir **Mi plan → Piernas → Entrenar**. Con Laura, la ruta
de entrenamiento redirige al listado de deportistas. Los mocks mantienen los
registros en memoria; se reinician al recargar el navegador.

```bash
npm run test
npm run lint
npm run build
```

Los tests cubren services, hooks, formulario, pantalla, roles y el recorrido
completo por `httpClient` y los mocks. También hay pruebas del token, los errores
y el refresh de `httpClient`. La prueba de integración comprueba que el recorrido
automatizado desde abrir el ejercicio hasta registrar la primera serie tarda
menos de diez segundos con mocks; falta medirlo con usuarios y el backend real.

La verificación con `VITE_USE_MOCKS=false` queda pendiente de la integración de
`POST /series`, `GET /plan-vigente`, `GET /sesiones/hoy` y
`GET /ejercicios/{id}/ultimas-series` en el backend. Esa integración no se simula
con datos locales cuando se elige el backend real.
